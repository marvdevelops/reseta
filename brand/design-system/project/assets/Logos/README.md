The Reseta logo: an R whose leg is a check mark, the prescription and the person checking it.

- `reseta-lockup.svg`: mark + wordmark, ink text. Welcome screen, website, store listing.
- `reseta-lockup-white.svg`: the same with white text, for `tinta` or dark grounds.
- `reseta-mark.svg`: the mark on its `tinta` tile. Tight spaces, favicon, notification icon.
- `reseta-app-icon.svg`: full-bleed square for the app stores, which apply their own mask.
- `reseta-wordmark.svg` / `reseta-wordmark-white.svg`: the word alone, outlined from Atkinson Hyperlegible Next Bold. Ink `#14213D` / white.
- `reseta-mark-ink.svg`: one-colour mark in ink `#14213D`, no tile, for print and stamps.

Colours are fixed in the files (`tinta` #2340B0, `highlighter` #FFD23F, white). Clear space: the height of the wordmark's "e". Minimum: mark 24px, lockup 120px wide.
