FieldCheck is one line of the prescription to confirm: the ink crop, what Reseta read, why it might be wrong, and two clear choices.

The consumer provides `label` (an everyday name), `value` (spelled out: "once a day", not "OD"), `state`, a one- or two-sentence `reason`, the `crop` URL, and `onMatch` / `onChange`. Show one FieldCheck per screen for the four critical fields (medicine, strength, how much, how often); the rest may stack.

- The crop is shown big, above the value, so the eye goes paper first.
- "Matches the paper" confirms only this field. There is no "accept all".
- In the `stop` state the match button is replaced by "Type it from the label": the value must come from the pharmacist or the label.
- Once confirmed, the row says "You checked this" and offers a quiet "Change".
