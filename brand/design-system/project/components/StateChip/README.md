StateChip shows how sure Reseta is about one value, always as an icon, a word and a colour together.

- `ok` → "Looks right" (`ok` on `ok-soft`) for a typed or printed value Reseta is confident about, and "Matches" once the user has confirmed it against the paper. Pass the word as children.
- `check` → "Check this" (`check` on `check-soft`): compare with the paper before confirming. Every handwritten medicine name starts here.
- `stop` → "Ask your pharmacist" (`stop` on `stop-soft`): nothing can be saved until the user types the value from the pharmacist or the label.

Never show a percentage or a confidence score. Never use these colours for anything else.
