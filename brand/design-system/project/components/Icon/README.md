Icon draws Reseta's ten icons in the logo's own stroke: 24 grid, 2.25 stroke, round caps and joins.

Names: check, alert, stop, camera, clock, pill, person, speaker, back, plus. The consumer provides `name`, and optionally `size` (default `icon-md`, 28px) and `color` (default the text colour around it). Always put an icon beside its word; never use one alone as a button.
