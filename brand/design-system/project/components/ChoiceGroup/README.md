ChoiceGroup asks one question with a few big answers, each a full-width tile with a tick.

Use it for who the medicine is for, how often (once a day / twice a day / every 8 hours), and alarm or quiet reminder. The consumer provides the question as `label`, the `options` (each with a `label` and an optional plain-words `hint`), the current `value` and `onChange`.

Keep to six options at most; add "Someone else" or "Other" last. Never use a dropdown or a small radio button instead.
