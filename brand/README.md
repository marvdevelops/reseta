# Reseta brand

- `logo/`: the logo as SVG (mark, app icon, wordmark, lockups, one-colour mark) and `logo/png/` (app icon, splash, favicon). The app's copies are in `rx-app/assets/`.
- `design-system/project/`: the source of the published design system (tokens, brand book, components). The app's version of the tokens and components is `rx-app/src/ui/kit.tsx`; change both together.
- `samples/`: ink crops from the synthetic sample prescription, used in component previews.
